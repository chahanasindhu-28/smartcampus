# Smart Campus Platform

Smart Campus Platform is a modern full-stack web application designed to digitize and simplify campus activities through a centralized and interactive platform.

The project replaces traditional notice boards, paperwork, and manual event management systems with a smart digital ecosystem that improves student engagement and administrative efficiency.

## Core Features

### Event Ticketing System
Students can register for campus events with a single click and instantly receive a digital QR code ticket for secure and fast event check-ins.

### Gamification & Leaderboard
The platform encourages student participation using a reward-based points system. Students earn points for joining clubs and attending events, while top participants are displayed on a live campus leaderboard.

### Auditorium Booking Management
Clubs can digitally request auditorium bookings without manual paperwork. Faculty/Admins can approve or reject requests directly through the dashboard.

### AI-Powered Promotion Tool
Club admins can generate promotional content automatically using AI for platforms like WhatsApp and Instagram to improve event reach and engagement.

# Why These Technologies Were Used

### React.js
Used to build a fast, component-based, and interactive user interface.

### Tailwind CSS
Used to create a premium glassmorphism UI with responsive modern styling.

### Framer Motion
Used for smooth animations and professional user experience.

### Node.js & Express.js
Used to create secure REST APIs and handle backend logic efficiently.

### JWT Authentication
Used for secure login authentication and role-based access control.

### SQLite
Used as a lightweight and fast local database solution.

### Prisma ORM
Used to simplify database operations using clean and readable JavaScript instead of raw SQL queries.
